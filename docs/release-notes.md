v1.13.1 改善 YouTube 長影片與 Shorts 的按鈕、選單及字幕位置。

- Shorts 按鈕依標題列實際高度下移，字幕預留底部資訊與右側操作列，減少文字及控制重疊。
- 若 Shorts 操作列放在影片外，外側選單會避開該操作列，必要時換到另一側。
- 長影片字幕預留原生控制列空間；小播放器與 Shorts 旁有空間時，選單放在影片外側。
- 選單留在影片內時，有空間就把字幕放進空出的閱讀區；外側選單不再讓字幕無故偏左。窄視窗可捲動選單，長設定頁保留返回與關閉按鈕。
- 小播放器中的字幕依長寬限制顯示大小，保留使用者原本儲存的字級；全螢幕依可見尺寸重新安排。
- 原按鈕捲出可見視窗時收合選單；支援可見視窗縮放與尺寸變動，沒有新增持續掃描整頁的觀察器。

保留優先人工字幕、基本分句、對話過濾、字幕下載、模型設定及原有網站自動翻譯規則。開選單不會開始 AI 翻譯；測試使用本機字幕與模擬橋接。

更新後重新整理 YouTube 分頁即可套用。公開套件不含作者帳號或個人機器設定，沒有加入會員功能或額外付費服務。
