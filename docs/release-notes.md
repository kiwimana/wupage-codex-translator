v1.14.0 調整懸浮球操作，平時只顯示翻譯球，移入才展開一個設定齒輪。

- 點擊主球翻譯／恢復原文，拖曳調整位置；保留 52px 主球與周圍可點擊範圍。
- 滑鼠移入或鍵盤聚焦主球時顯示唯一的設定按鈕，不再因懸停就打開整個面板。
- 點齒輪開啟設定面板，再點一次、點外側或按 Escape 關閉；移開滑鼠仍可繼續操作已開啟的設定。
- 靠近視窗底部時設定按鈕移到主球上方；隱藏時不攔截網頁點擊，也不進入 Tab 順序。
- 保留觸控長按設定、鍵盤捷徑、主題、模型與字幕偏好，不新增其他浮球入口。

此版本同時提供 Firefox 與 Chrome 套件。展開浮球或開啟設定不會啟動 AI；驗證使用獨立測試瀏覽器及本機模擬回應，不執行真實帳號翻譯或登入。
