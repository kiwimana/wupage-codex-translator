v1.9.3 修正 Codex 桌面版更新後，翻譯出現 `codex.exe ENOENT` 的問題。

- 原本設定的 Codex 執行檔被更新移除時，橋接會自動在本機 Codex 安裝目錄尋找仍有效的版本，略過空的更新資料夾。每次請求重新檢查，不再一直使用已失效的版本路徑。
- 偵測工具、翻譯及手動開啟 Codex 登入均支援路徑復原。仍存在的自訂路徑會繼續使用。
- 更新進行中暫時沒有執行檔時，顯示等待更新後重試的提示；不自動重送翻譯。

**請一併更新 Windows 橋接程式並執行安裝程式。** 只更新瀏覽器擴充不會替換本機橋接。詳細步驟見[本機橋接說明](https://github.com/kiwimana/wupage-codex-translator/blob/codex-firefox/native-chatgpt/README.md)。

保留 v1.9.2 的 YouTube 控制列效能修正、CC 載入提示及擴充更新功能。此次路徑偵測不讀取帳號登入內容，也不會自動登入或開始翻譯。公開套件不含作者登入檔或機器路徑。
