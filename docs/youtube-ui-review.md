# YouTube 播放器操作改進

參考範圍：沉浸式翻譯 1.34.2 的字幕設定介面、使用者提供的播放器選單，以及獨立 Firefox 中的公開 YouTube 長影片與 Shorts 頁面。僅參考操作與資訊排列，使用 WuPage 自己的程式及既有 CC0 圖示；不複製對方的程式或素材。

| 細節 | 改進前 | v1.11.0 |
| --- | --- | --- |
| 長影片與 Shorts 入口 | 長影片開選單，Shorts 是翻譯和齒輪兩個按鈕 | 帳號版統一為單一 AI 字幕入口；左鍵開關選單，右鍵開選單 |
| 常用設定 | 字體和語言需進第二層 | 第一層直接調整翻譯語言、字幕大小，與詳細設定同步 |
| 操作範圍 | 自動翻譯開關容易被理解成只處理這部影片 | 「僅本次開啟字幕翻譯」為主要操作；網站自動翻譯獨立標明 |
| 設定密度 | 顏色、服務、字幕來源與大小混在長表單 | 先呈現預覽與常用外觀，來源、顏色、字體及時間偏移收進進階區 |
| Shorts 畫面 | 選單覆蓋直式影片，字幕接近底部資訊 | 有空間時將選單放到影片外側；字幕預留底部資訊空間 |
| 收合與定位 | 再點原按鈕不一定收合，捲動時選單可能離開按鈕 | 保留原按鈕點擊事件，支援再點收合、Esc、外側點擊及隨頁面捲動定位 |
| 載入提示 | 部分圖示旋轉，啟動後選單仍覆蓋畫面 | 使用獨立載入圈；選擇本次翻譯後收合選單，播放器按鈕保留狀態 |

v1.12.0 補上優先人工字幕、基本分句最佳化、對話內容篩選，均可單獨開關。人工目標語言字幕可直接顯示；分句只在本機處理英文自動字幕；音效篩選保留不確定文字。使用限制及預設值見 README。字幕服務的獨立全域設定尚未加入；會員 AI 智慧分句也不加入。

本次亦讀取使用者現有 Firefox 長影片控制列的輔助使用介面位置資料，確認 WuPage 按鈕比參考擴充寬。v1.12.0 將原生按鈕由 52px 收斂到 44px，保留點擊範圍；第一層選單由 304px 縮為 288px，詳細設定仍為 352px。未取得瀏覽器的 activeTab 擷取權限時，不以其他桌面視窗的畫面代替參考頁。

本次參考測試未登入第三方擴充；Shorts 頁面未出現其專屬字幕快捷選單，不能由此推論所有 Shorts 都不支援。WuPage 的長影片、Shorts、窄視窗與全螢幕操作另以本機字幕及獨立瀏覽器測試，不使用真實 AI 帳號翻譯。

開選單、調整外觀及下載已完成字幕不會新增翻譯工作。網站自動翻譯仍需使用者主動啟用；未開翻譯時不增加定時字幕翻譯或播放器全頁掃描。
